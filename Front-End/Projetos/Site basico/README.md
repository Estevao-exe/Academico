# 💻 Learn JS - Manipulação de DOM e Temas

Um projeto simples e prático desenvolvido para estudar e praticar a manipulação do DOM (Document Object Model) utilizando **HTML**, **CSS** e **JavaScript** puro.

## 🚀 Funcionalidades

* **Alternância de Tema (Light/Dark Mode):** Um botão na barra de navegação permite alternar entre o tema claro e o tema escuro, alterando cores de fundo, textos e ícones dinamicamente.
* **Cursor Personalizado:** Um elemento circular que segue os movimentos do ponteiro do mouse pela tela em tempo real.
* **Barra de Navegação:** Menu simples construído com Flexbox.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização, transições suaves (`transition`), layout com Flexbox e classes de controle de tema.
* **JavaScript (ES6+):** Manipulação de eventos (`click` e `mousemove`), alteração dinâmica de classes e textos.

## 📂 Estrutura de Arquivos

```text
📁 nome-do-projeto
 ├── 📄 index.html   # Estrutura principal da página
 ├── 🎨 style.css    # Estilos, temas claro/escuro e cursor
 └── ⚡ script.js    # Lógica de interação e eventos
```

## 🔧 Como Executar o Projeto

1. Clone este repositório ou baixe os arquivos:
   ```bash
   git clone https://github.com
   ```
2. Certifique-se de que os arquivos `index.html`, `style.css` e `script.js` estejam na mesma pasta.
3. Abra o arquivo `index.html` diretamente no seu navegador de preferência (Chrome, Firefox, Edge, etc.).

## 📝 Notas de Aprendizado

Durante o desenvolvimento deste projeto, foram praticados os seguintes conceitos:
* Seleção de elementos com `document.getElementById()`.
* Escuta de eventos com `addEventListener()`.
* Manipulação de classes CSS via JS utilizando `classList.toggle()`.
* Captura de coordenadas do mouse (`clientX` e `clientY`).
