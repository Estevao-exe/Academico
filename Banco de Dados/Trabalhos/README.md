## 📚 Banco de Dados

Este repositório tem como objetivo organizar e armazenar os materiais e atividades relacionados à matéria de Banco de Dados.

📖 Conteúdos

Aqui serão adicionados:

Atividades e exercícios realizados em aula
Projetos desenvolvidos durante a matéria
Trabalhos individuais e em grupo
🎯 Objetivo

Manter um registro dos estudos e trabalhos realizados durante o período letivo, facilitando a organização, consulta, revisão e acompanhamento do aprendizado.
