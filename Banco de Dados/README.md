# 📚 Modelagem de Banco de Dados
## 📌 Sobre o repositório

Este repositório tem como objetivo registrar o processo de aprendizagem e as atividades desenvolvidas durante as aulas de Modelagem de Banco de Dados.

Aqui serão armazenados exercícios, códigos SQL, exemplos práticos e anotações sobre os conteúdos estudados em sala de aula, servindo como um ponto de partida para consultas, revisões e desenvolvimento de futuros projetos.

## 🎯 Objetivos
Registrar os conteúdos aprendidos durante as aulas.
Praticar a criação e organização de bancos de dados.
Compreender a estrutura e o relacionamento entre tabelas.
Desenvolver habilidades com comandos SQL.
Documentar exercícios e atividades realizadas.
Construir uma base de conhecimento para projetos futuros.

### 📖 Conteúdos estudados

Ao longo das aulas, serão registrados assuntos como:

Introdução à modelagem de banco de dados.
Banco de dados relacionais.
Criação de bancos de dados e tabelas.
Tipos de dados.
Chaves primárias (PRIMARY KEY).
Chaves estrangeiras (FOREIGN KEY).
Relacionamentos entre tabelas.
Inserção, alteração e exclusão de dados.
Consultas SQL (SELECT).
Junções entre tabelas (JOIN).
Subconsultas.
Funções (FUNCTION).
Procedimentos armazenados (PROCEDURE).

## 💻 Ferramentas utilizadas
MySQL: sistema de gerenciamento de banco de dados.
MySQL Workbench: ferramenta utilizada para criar, consultar e administrar bancos de dados.
SQL: linguagem utilizada para manipulação e consulta de dados.

## 🗂️ Organização do repositório

Os arquivos serão organizados conforme os conteúdos e atividades desenvolvidas em sala de aula.

Exercicios/ – atividades práticas realizadas durante as aulas.
Scripts_SQL/ – códigos utilizados na criação e manipulação dos bancos de dados.
Modelagem/ – modelos e estruturas dos bancos de dados.
Anotacoes/ – registros e explicações dos conteúdos aprendidos.

## 📝 Registro das atividades

Este espaço será atualizado conforme o desenvolvimento das aulas, reunindo os exercícios realizados, os conhecimentos adquiridos e as dificuldades encontradas durante o processo de aprendizagem.

## 🚀 Objetivo futuro

Utilizar os conhecimentos adquiridos para desenvolver bancos de dados mais completos e organizados, aplicando os conceitos de modelagem e SQL em situações práticas e projetos reais.

## 📚 Conclusão

Este repositório representa o início de uma jornada de aprendizagem em Modelagem de Banco de Dados. A proposta é documentar a evolução dos conhecimentos, manter as atividades organizadas e construir uma referência para estudos e consultas futuras.
